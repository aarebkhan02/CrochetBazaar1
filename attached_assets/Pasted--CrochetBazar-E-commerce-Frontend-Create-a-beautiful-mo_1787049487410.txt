# CrochetBazar — E-commerce Frontend

Create a beautiful, modern, responsive ecommerce frontend called **“CrochetBazar”** for a small handmade crochet business.

The website should feel **warm, elegant, cute, handmade, and premium**, while remaining simple and easy to use.

## Brand

**Name:** CrochetBazar

**Tagline:** “Handmade with love 🧶”

Use a soft handmade aesthetic with:

* Cream/off-white backgrounds
* Soft pink, peach, lavender and warm brown accents
* Rounded cards and buttons
* Subtle shadows
* Elegant typography
* Small crochet/flower-inspired decorative elements
* Smooth hover animations
* Clean and uncluttered layout

Do not make it look like a generic corporate ecommerce website.

---

## Navbar

Create a responsive navbar containing:

* CrochetBazar logo/name
* Home
* Shop
* Categories
* About
* Contact
* Search icon
* Cart icon with item count

On mobile, use a hamburger menu.

Make the navbar sticky while scrolling.

* Product name
* Price
* Category
* Description
* Quantity selector
* Add to Cart
* Buy Now
* WhatsApp Order button

Example description:

---

## Shopping Cart

Create a functional frontend cart.

Cart should show:

* Product image
* Product name
* Price
* Quantity +/− controls
* Remove button
* Individual item total
* Subtotal
* Delivery charge
* Grand total

Use localStorage so the cart remains after refreshing the page.

Show:

**Payment Method: Cash on Delivery (COD)**

Do not implement online payment.

---

## Checkout / Place Order

Create a simple checkout form.

Fields:

* Full Name
* Mobile Number
* Delivery Address
* City
* State
* Pincode
* Optional Order Note

Show an order summary on the right.

Payment method:

### 💵 Cash on Delivery

Clearly mention:

**“Pay when your order is delivered.”**

After clicking **Place Order**, do NOT implement a real payment gateway.

Instead, create a WhatsApp order flow.

---

## WhatsApp Ordering

Add a prominent:

**“Order on WhatsApp”**

button.

When clicked, redirect the customer to WhatsApp using a WhatsApp URL with a pre-filled message.

The message should automatically contain:

* Customer name
* Products ordered
* Quantities
* Prices
* Total amount
* Delivery address
* Payment method: COD

Example generated message:

“Hello CrochetBazar! 🧶

I would like to place an order:

🌸 Crochet Rose × 2 — ₹258
🌼 Crochet Gajra × 1 — ₹249

Total: ₹507

Name: Customer Name
Mobile: 98XXXXXXXX
Address: Customer Address
Payment: Cash on Delivery

Thank you! ❤️”

Use a configurable WhatsApp number in the frontend so the business owner can easily replace it with their actual number.

Also add a WhatsApp icon/button in the navbar or contact section.

---

## UI / UX Requirements

Make the website:

* Fully responsive
* Mobile-first
* Beautiful on desktop and mobile
* Fast and lightweight
* Smooth scrolling
* Smooth hover animations
* Subtle page transitions
* Attractive product cards
* Clean spacing
* Rounded corners
* Accessible buttons
* Loading states where appropriate
* Empty cart state
* Product search
* Category filtering
* Cart persistence using localStorage

Use animations carefully. Avoid excessive animations.

---

## Technical Requirements

Build this as a **frontend-only application**.

Recommended stack:

* React.js
* Vite
* Tailwind CSS
* React Router
* Lucide React icons
* LocalStorage for cart state

No backend is required.

No database is required.

No online payment gateway is required.

No authentication is required.

Use dummy/local product data.

Keep all product information in a single easy-to-edit data file.

Keep the WhatsApp number in one configuration variable so the shop owner can easily change it.

---

## Important

The provided crochet product images should actually be used throughout the website rather than using generic stock images.

Make the final website feel like a **real small Indian handmade crochet brand**, not a template.

The overall experience should be:

**Browse → View Product → Add to Cart → Checkout → WhatsApp → COD Order**

Focus heavily on a **beautiful visual presentation of the crochet products**.
